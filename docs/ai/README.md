# AI documentation

Agent-oriented aeco-dev GUI docs in one place:

| File | Purpose |
| --- | --- |
| [SKILL.md](./SKILL.md) | Usage rules, component selection, do/don't, accessibility. Copied into `@aeco-dev/gui` on every build. |
| [aeco-dev-gui.json](./aeco-dev-gui.json) | Full public API inventory. Written into `@aeco-dev/gui` on every build. |
| [component-index.md](./component-index.md) | Generated public export inventory and emitted classes |

HTML versions (`SKILL.html`, `component-index.html`) are produced by `npm run docs`.
