Panel

Status: Stable
Category: shell
Import: @aeco-dev/layout
Emitted class(es): CollapsiblePanel

Docked panel for a Layout region. Exported as Panel from @aeco-dev/layout.

Pass the layout instance directly. Content goes in with add. Call bindTo or layout.bindToggle with a button the application owns.

Methods

  • show() / hide() / toggle() / select()
  • add(...) — append content (inherited)
  • bindTo(element) / unbind() — wire a button the app owns
  • setLabel(label)
  • detachToFloatingWindow() / isFloating() / getFloatingWindow()
  • isVisible() / isSelected()
  • destroy()

Source: src/components/panels/WorkspacePanel.js

Import

import { Panel } from "@aeco-dev/layout";

Examples

Usage

const layers = new Panel({
  layout,
  position: "left",
  id: "layers",
  label: "Layers",
  title: "Layers",
  floatable: true,
});
layers.add(new Text("Layer list"));
layers.show();
