World

Status: Stable
Category: shell
Import: @aeco-dev/layout
Emitted class(es): World

Application shell. The default constructor builds the standard regions (ribbon, left, right, bottom, viewport, footer). Pass a config node that has an id to use that tree instead.

Region ids the layout looks up: RibbonMenu, HeaderBar, LayoutToggleBar, WorkspaceLeft, WorkspaceRight, WorkspaceBottom, Viewport, Footer.

Source: src/layout/World.js

Import

import { World } from "@aeco-dev/layout";

Examples

Usage

const world = new World();
world.mount(document.body);

const layout = new Layout({ leftOpen: true }).init(world);
