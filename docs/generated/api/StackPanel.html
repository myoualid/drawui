StackPanel

Status: Stable
Category: layout
Import: @aeco-dev/gui
Emitted class(es): Row, Column

Flex row or column container.

Source: src/primitives/ui.js

Import

import { StackPanel } from "@aeco-dev/gui";

Examples

StackPanel (row)

return new StackPanel({ isVertical: false })
  .gap("0.5rem")
  .add(new Badge("Row"))
  .add(new Badge("Layout"));

StackPanel (column)

return new StackPanel({ isVertical: true })
  .gap("0.25rem")
  .add(new Text("Column A"))
  .add(new Text("Column B"));
