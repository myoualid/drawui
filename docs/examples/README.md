# aeco-dev GUI examples

Static browser demos for the `dist/gui.js` and `dist/layout.js` builds. No bundler required — only a local HTTP server (ES modules do not load over `file://`).

Example pages link `examples/examples.css` after aeco-dev GUI CSS to re-enable document scrolling (aeco-dev GUI’s reset locks `html`/`body` to `overflow: hidden` for full-viewport apps).

## Run locally

Build first, then serve the `docs/` folder:

```powershell
npm run build
npx --yes serve docs -p 5173
```

Or use the combined script:

```powershell
npm run examples
```

Then open:

- **Docs hub:** http://localhost:5173/
- **Templates:**
  - 3D Viewer (workspace shell) — http://localhost:5173/examples/templates/
  - Site Logistics (AppShell) — http://localhost:5173/examples/templates/site/
  - Ops Board (split layout) — http://localhost:5173/examples/templates/ops/
- **Quick start:** http://localhost:5173/examples/min/

For GitHub Pages, set the site source to the `/docs` folder — [`index.html`](../index.html) is the entry.

> Previously at `/examples/min-components/` — that folder was renamed to `components/`.

## Min example

[`min/index.html`](./min/index.html) loads the GUI browser build:

```html
<link rel="stylesheet" href="../../dist/gui.css">
<script type="importmap">
{ "imports": { "@aeco-dev/gui": "../../dist/gui.js" } }
</script>
```

`dist/gui.css` includes icons, themes, and optional widget styles.

After npm publish, swap the paths for CDN URLs:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@aeco-dev/gui@0.2.3/gui.css">
<script type="module">
  import { Button } from "https://cdn.jsdelivr.net/npm/@aeco-dev/gui@0.2.3/gui.js";
</script>
```

## Live demo sources (internal)

[`components/demos.js`](./components/demos.js) and [`demos.full.js`](./components/demos.full.js) are the **source of truth** for live previews on API / TypeDoc pages. Edit those (and `catalog.manifest.json`), then run `npm run docs`.

The optional gallery shells (`components/index.html`, `full.html`) are developer tools for previewing demos locally — they are not linked from the docs hub.

| File | Role |
| --- | --- |
| `catalog.manifest.json` | Human-edited categories and demo assignments |
| `catalog.json` | Generated by `npm run docs` |
| `demos.js` | GUI preview renderers keyed by demo id |
| `demos.full.js` | Optional-widget and layout preview renderers (chart, spreadsheet, gantt, Showdown markdown, Layout) |
| `gallery.js` | Optional AppShell preview host (`{ build: "min" \| "full" }`) |
| `../spa-host.css` | Full-viewport host styles for SPA examples |

## Optional library import map

[`components/full.html`](./components/full.html) maps `@aeco-dev/gui` and `@aeco-dev/layout`, and pins Chart.js, AG Grid, jsGantt, Showdown, and Highlight.js to jsDelivr:

- `chart.js@4.4.7`
- `ag-grid-community@35.2.1`
- `jsgantt-improved@2.8.10`
- `showdown@2.1.0`
- `@highlightjs/cdn-assets@11.11.1`

See [publishing.md](../publishing.md) and `docs/dist/importmap.full.json` for the complete import map template.

## Templates

Three demos with **different layouts** — not the same ribbon/workspace chrome:

| Demo | Path | Shape | Imports |
| --- | --- | --- | --- |
| 3D Viewer | [`templates/`](./templates/) | `new World()`, `new Layout().init(world)`, docked `new Panel()` | `@aeco-dev/gui` + `@aeco-dev/layout` |
| Site Logistics | [`templates/site/`](./templates/site/) | `AppShell` SPA (sidebar routes) | `@aeco-dev/gui` — Chart, DataGrid, GanttChart, Markdown |
| Ops Board | [`templates/ops/`](./templates/ops/) | Header + `SplitContainer` + tabs + `StatusBar` | `@aeco-dev/gui` — Chart, DataGrid, NodeGraph |

### 3D Viewer (workspace shell)

`new World()` builds the shell. `new Layout(config).init(world)` owns regions. Each `new Panel()` owns chrome. Undock → `FloatingWindow`.

| File | Role |
| --- | --- |
| [`index.html`](./templates/index.html) | Full-viewport entry |
| [`world-config.js`](./templates/world-config.js) | Region ids and ribbon button ids |
| [`app.js`](./templates/app.js) | Mount world, panels, viewport card |
| [`templates.css`](./templates/templates.css) | Host chrome |

### Site Logistics / Ops Board

Both load `dist/gui.js` with the same optional-library import map as [`components/full.html`](./components/full.html) (Chart.js, ag-grid, jsGantt, Showdown).

- **Site** — construction plant bookings, timesheets, delivery windows, look-ahead Gantt, daily briefing markdown.
- **Ops** — alert rail + metrics/incidents/topology tabs (no workspace ribbon).

Open any template URL above after `npm run examples` (run `npm run build` first so `docs/dist/gui.js` exists).
